## 4. 正文/核心内容

### 4.1 系统概述

根据新原型分析、会议记录和商机模块变更文档，本CRM系统（治为CRM）是一个企业级客户关系管理平台，包含工作台、营销管理、客户管理、商机管理、报价管理、产品管理、绩效管理、报表中心等核心模块。系统采用"插入式"整合方式部署在现有CRM系统目录下。

**变更说明**: 
- 新原型地址: `http://localhost:5173/`，展示了完整的系统功能设计
- 实际部署地址: `http://192.168.2.97:6089/`
- 新增工作台仪表盘，包含销售漏斗、待办任务、活动日历
- 新增营销管理模块（线索池、我的线索）
- 新增产品管理模块（产品列表、产品分类）
- 新增报表中心模块
- 新增角色切换功能（支持销售、主管、财务、管理层、管理员角色）
- 商机模块和报价模块有重大功能更新

### 4.2 核心业务流程

#### 4.2.1 线索流转流程
```
线索录入（人工手动）→ 待领取池 → 销售领取 → 跟进转化 → 有效客户 / 无效标记
```

#### 4.2.2 商机管理流程
```
商机创建（直接/客户详情页）→ 方案报价 → 谈判 → 赢单/输单
```

#### 4.2.3 目标管理流程
```
目标设定 → 管理层审核 → 自动统计 → 目标对比
```

#### 4.2.4 报价流程（新增数据关联）
```
商机创建 → 添加产品明细 → 新建报价（自动带入产品）→ 审批 → 导出PDF → 转为订单
```

#### 4.2.5 工作台待办流程
```
待办生成规则 → 自动推送待办 → 待办查看 → 任务处理 → 待办关闭
```

#### 4.2.6 公海池流程
```
客户进入公海 → 销售领取 → 跟进转化 → 未跟进自动释放回公海
```

#### 4.3.10 数据一致性规则（新增）

| 序号 | 规则项 | 描述 | 验证方式 | 当前状态 |
|------|--------|------|----------|----------|
| 1 | 线索统计一致性 | 工作台线索统计数 = 线索列表中对应状态的线索数 | API查询比对 | 可执行 |

| 3 | 商机统计一致性 | 工作台商机统计数 = 商机列表中的商机总数 | API查询比对 | 可执行 |
| 4 | 成交金额一致性 | 驾驶舱成交金额 = 所有赢单商机金额之和 | API查询比对 | 可执行 |
| 5 | 销售漏斗一致性 | 各阶段商机数之和 = 总商机数 | 图表数据比对 | 可执行 |
| 6 | 趋势数据一致性 | 月度趋势数据 = 当月每日数据汇总 | API查询比对 | 可执行 |

| 9 | 权限数据一致性 | 个人视角数据 = 该用户关联的数据 | 不同角色登录验证 | 可执行 |
| 10 | 实时数据一致性 | 数据更新后仪表盘数据及时刷新 | 操作后刷新验证 | 可执行 |
