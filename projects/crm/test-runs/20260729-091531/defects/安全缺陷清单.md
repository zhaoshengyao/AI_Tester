## 修复建议

### P0 - 立即修复

**SEC-001: 禁止访问.git目录**
```nginx
location ~ /\.git {
    deny all;
}
```

**SEC-003: 禁止访问.env文件**
```nginx
location ~ /\.env {
    deny all;
}
```

### P1 - 3天内修复

**SEC-002: 配置文件移出Web根目录**
- 将config.ini移到Web根目录以外的位置
- 或配置Web服务器禁止访问

**SEC-004: 移除示例配置文件**
- 删除.env.example文件
- 或配置Web服务器禁止访问

### P2 - 1周内修复

**SEC-005/006: 禁用API文档**
- 生产环境禁用Swagger和API文档
- 或配置访问权限（IP白名单/密码保护）

## 预防措施

1. **部署前检查清单**：
   - 确认.git目录不在Web根目录
   - 确认.env文件不可被公网访问
   - 确认Swagger/API文档已禁用或受保护

2. **自动化扫描**：
   - 将安全扫描纳入CI/CD流程
   - 每次部署前自动执行安全检查

3. **WAF配置**：
   - 部署Web应用防火墙
   - 配置敏感文件访问规则
