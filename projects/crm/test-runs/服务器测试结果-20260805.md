## 四、与 Linux 环境相关的特殊注意事项

1. **浏览器依赖**: Linux 上需要额外安装 `mesa-libgbm`、`libxkbcommon`、`libxrandr`、`libxcomposite`、`libxdamage`、`libxshmfence`、`libasound` 等库
2. **路径差异**: Linux 使用 `/home/zhiwei/AutoTestHub`，Windows 使用项目根目录
3. **Shell 差异**: Linux 使用 `.sh` 脚本，Windows 使用 `.ps1` 脚本
4. **权限差异**: Linux 需要 `chmod +x` 确保脚本可执行
