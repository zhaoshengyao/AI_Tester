## 接口基础信息

### 认证方式
- **登录接口**: `POST /prod-api/auth/login`
- **认证参数**: `username`, `password`, `clientId`, `grant_type`, `grantType`
- **Token位置**: `data.access_token`
- **请求头**: `Authorization: Bearer {token}`, `clientid: {client_id}`

### 响应结构
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```
