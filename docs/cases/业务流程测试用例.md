## 核心业务流程总览

| 流程编号 | 流程名称 | 流程描述 |
|----------|----------|----------|
| BP1 | 线索流转流程 | 线索录入 → 待领取池 → 销售领取 → 跟进转化 → 有效客户/无效标记 |
| BP2 | 商机管理流程 | 商机创建 → 方案报价 → 谈判 → 赢单/输单 |
| BP3 | 报价流程 | 商机创建 → 添加产品明细 → 新建报价 → 审批 → 导出PDF → 转为订单 |
| BP4 | 公海池流程 | 客户进入公海 → 销售领取 → 跟进转化 → 未跟进自动释放回公海 |
| BP5 | 待办流程 | 待办生成 → 自动推送 → 待办查看 → 任务处理 → 待办关闭 |
| BP6 | 目标管理流程 | 目标设定 → 管理层审核 → 自动统计 → 目标对比 |
